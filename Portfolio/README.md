# Jettipogu Jhansi - Personal Portfolio Website

A modern, professional, responsive portfolio website for **Jettipogu Jhansi**, a Computer Science Engineering student and aspiring software developer.

Designed specifically for campus placements, internship applications, and fresher software engineering roles.

---

## 🎨 Theme & Design System

- **Palette**: White, Navy Blue (`#0A192F`, `#1E3A8A`), and Light Blue (`#0284C7`, `#38BDF8`)
- **Typography**: Google Fonts (*Plus Jakarta Sans* for clean, modern readability; *Fira Code* for tech tags)
- **Icons**: Font Awesome 6
- **Features**:
  - 🌓 **Dark & Light Mode Toggle** with persistent state in `localStorage`
  - 📱 **100% Fully Responsive** on mobile, tablet, and desktop
  - 📜 **Interactive Education Timeline** with CGPA badges
  - 🛠️ **Categorized Technical Skills Cards** (No invented proficiency percentages)
  - 💼 **Project Showcase Cards** linking to official GitHub profile
  - 🏢 **Internship Experience Card** for LifeBoxNextGen
  - 📜 **Interactive In-Browser Resume Modal** with "Print / Save PDF" feature
  - 📄 **Dedicated Standalone Resume Page** (`resume.html`)
  - 📬 **Interactive Contact Form** with real-time feedback and direct `tel:` & `mailto:` links
  - ⬆️ **Floating Back-to-Top Button** with smooth scroll
  - ⚡ **Zero-dependency, vanilla HTML5, CSS3, and modern ES6 JavaScript** (blazing fast loading times)

## 🚀 How to Run Locally

1. **Directly in Browser**:
   - Double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Safari).

2. **Using a Local Server (Recommended)**:
   - With Python:
     ```bash
     python -m http.server 3000
     ```
     Then open `http://localhost:3000` in your browser.

## 🌐 Free Deployment Options

### Option 1: GitHub Pages
1. Push this folder to a GitHub repository named `portfolio` or `jettipogujhansi2025.github.io`.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. The website will be live in seconds!

### Option 2: Vercel or Netlify
- Drag and drop the `Portfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
- No build command needed; static HTML will deploy instantly.
